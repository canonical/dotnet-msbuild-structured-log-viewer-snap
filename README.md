# MSBuild Structured Log Viewer Snap

A snap package for [MSBuild Structured Log Viewer](https://github.com/KirillOsenkov/MSBuildStructuredLog), a powerful logger and interactive viewer for MSBuild build logs.

## About

MSBuild Structured Log Viewer is a tool that records a structured representation of executed targets, tasks, property and item values during MSBuild builds. It provides:

- **Binary Log Format (*.binlog)**: A portable, structured log interchange format
- **Rich Interactive Viewer**: Visualize and analyze MSBuild execution in detail
- **Build Investigation**: Simplifies debugging and understanding complex builds
- **Cross-platform Support**: Works on Linux, Windows, and macOS

This snap packages the Avalonia-based cross-platform version of the log viewer for easy installation and usage on Linux systems.

## Installation

### From the Snap Store

```bash
sudo snap install msbuild-structured-log-viewer
```

### Connect Optional Interfaces

To allow the viewer to access your `.nuget/packages` directory for resolving NuGet dependencies when building projects, connect the `dot-nuget-packages` interface:

```bash
sudo snap connect msbuild-structured-log-viewer:dot-nuget-packages
```

## Usage

Launch the application from your application menu or run:

```bash
msbuild-structured-log-viewer
```

### Opening Binary Logs

The viewer can open `.binlog` files generated by MSBuild. To create a binary log during a build:

```bash
dotnet build /bl
# or
msbuild /bl YourProject.sln
```

This creates a `msbuild.binlog` file that you can open with the viewer.

## Building the Snap Locally

### Prerequisites

- [snapcraft](https://snapcraft.io/docs/installing-snapcraft)
- [LXD](https://ubuntu.com/lxd) or [Multipass](https://multipass.run/) (for building in a clean environment)

### Build Commands

```bash
# Clone the repository
git clone https://github.com/canonical/dotnet-msbuild-structured-log-viewer-snap.git
cd dotnet-msbuild-structured-log-viewer-snap

# Build the snap
snapcraft

# Install the locally built snap
sudo snap install --dangerous msbuild-structured-log-viewer_*.snap
```
